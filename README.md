# Pharmacy-Tutor

**面向药学教师的 AI 备课与复习支架系统** —— 以"先生理、后药理"纵向整合为教学契约，结合教材证据检索与来源可溯的生成管线，辅助教师完成药理学课程材料的起草与复习。

> **An AI-assisted lesson-preparation and review scaffold for pharmacology educators.** Pharmacy-Tutor generates physiology-first, vertically integrated teaching materials grounded in a textbook evidence-retrieval pipeline, under explicit teacher supervision. It is a teaching scaffold — **not a clinical decision-support system**.

## 项目定位

- **使用对象**：药理学课程教师（备课、习题、病例、复习材料起草）。
- **设计原则**：生理机制先行、药理应用在后；每条生成内容附带可核对的教材来源卡片。
- **边界声明**：本系统是教师监督下的备课/复习支架，不是临床决策系统，不用于患者个体化诊疗。

## 核心能力

| 能力 | 说明 |
|---|---|
| 教材证据检索 | 多通道检索管线：语义召回 → 逐条证据判定 → 来源多样性排序；支持实体锚点字面召回与逐锚点补全 |
| 教学契约 | 三段式生成结构 + 生理优先纵向整合，作为生成指令约束输出形态 |
| 来源卡片 | 每条入选证据标注来源通道（语义/关键词/锚点/生理提示/公开资料）与教材出处 |
| 诚实降级 | 检索无果时如实返回"无证据"回答而非编造；Jev 判定不可用时自动降级并在诊断中标记 `degraded` |
| 来源限定 | 提问点名教材时限定检索范围；中英文教材间支持跨语言查询 |
| 会话与安全 | SQLite 会话持久化、访问门控、限流、SSE 流式响应 |

## 技术栈

- **后端**：Python / FastAPI，检索编排 + 教学契约 + 会话持久化
- **前端**：React / Vite
- **检索内核**：SAG-Wiki SAG2 管线（BM25 候选召回 → 逐条证据判定 → 多样性排序），配本地判定桥
- **语料**：7 个药理学教材语料（中文教材 + 英文经典教材 + 药物数据库），OCR 文本经行号映射对齐；**属教研室内部材料，不对外分发**
- **模型接入**：OpenAI 兼容接口（生成 + 判定）

## 已验证的工程事实

以下为供给侧工程指标（截至 2026-11 实测），**不代表答案质量或教学效果**：

- 7 个教材文件索引就绪；后端单元测试 26 项通过
- 15 题冻结证据供给基准：实体锚点覆盖率 77%（v1 混合检索为 68%），暖缓存延迟中位 6.9s
- 判定缓存实测命中 2,493 次 / 持久判定 5,483 条
- 无证据路径、双语启发式、流式推送、访问门控均经端到端冒烟验证

## 证据边界（重要）

- 来源卡片展示的是**检索上下文**，不是逐条论断的引用核验。
- 教材文本来自 OCR，可能损坏药名、剂量、否定词与公式；歧义会披露而非静默纠正。
- 三段式结构是**生成指令**，不验证语义正确性。
- **教学效果、生理准确性、临床安全性均未建立**；"检索得到相关片段"不等于"答案正确"。
- 检索诊断记录的是证据供给遥测，不是答案质量评分。
